## چی کار می‌کنه؟

- **نمای روز:** کارهای هر روز رو با ساعت، دسته‌بندی و اولویت بنویس. یه «تمرکز اصلی» برای روزت تعیین کن و کارهای ناتموم رو با یه دکمه به فردا بفرست.
- **نمای هفته:** کل هفته رو یه‌جا ببین و کارها رو بین روزها جابه‌جا کن.
- **برد کارها:** ستون‌های «برای انجام»، «در حال انجام» و «انجام شد». کارت‌ها رو بکش و رها کن، ستون جدید بساز و برای هر کار چک‌لیست، موعد و توضیحات بذار.
- **عادت‌ها:** عادت‌های روزانه رو تیک بزن و زنجیره‌ی روزهات رو نگه دار. پیشرفت ماه هم با درصد و سطح (از «تازه‌کار» تا «قهرمان») نشون داده می‌شه.
- **تمرکز (پومودورو):** تایمر ۲۵ دقیقه‌ای با زمان قابل تنظیم و یادآوری برای استراحت.
- **تقویم شمسی:** تاریخ‌ها شمسی‌ان و تاریخ میلادی هم کنارشون هست.
- **پیام‌های تشویقی:** با هر کار انجام‌شده یه پیام کوتاه و انرژی‌بخش می‌گیری.
- **پشتیبان‌گیری:** کل داده‌هات رو توی یه فایل ذخیره کن و هر وقت خواستی برگردون.
- **تم:** بین حالت‌های رنگی جابه‌جا شو.

## نصب و استفاده

طوطیا یه وب‌اپ (PWA) هست و نصب خاصی نمی‌خواد.

**روی گوشی:**
1. صفحه‌ی برنامه رو توی مرورگر باز کن.
2. توی آیفون از Safari گزینه‌ی **Add to Home Screen** و توی اندروید از Chrome گزینه‌ی **Install app** رو بزن.
3. از این به بعد مثل یه اپ معمولی و حتی بدون اینترنت بازش کن.

**روی کامپیوتر:**
فایل `index.html` رو توی مرورگر باز کن، یا ریپو رو با GitHub Pages منتشر کن.

```bash
git clone https://github.com/gwatdesign/tootia.git
cd tootia
# فقط index.html را در مرورگر باز کن
```

> برای اینکه حالت آفلاین و نصب روی گوشی کار کنه، برنامه باید از یه آدرس `https` (مثل GitHub Pages) باز بشه.

## داده‌هات کجا ذخیره می‌شه؟

همه‌چیز فقط روی دستگاه خودت و توی حافظه‌ی مرورگر (`localStorage`) ذخیره می‌شه. هیچ سروری در کار نیست و چیزی جایی فرستاده نمی‌شه.
اگه مرورگر رو پاک کنی یا دستگاه رو عوض کنی، از بخش **بیشتر ← پشتیبان‌گیری** یه فایل پشتیبان بگیر و روی دستگاه جدید **بازیابی** کن.

